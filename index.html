Air Pollution Gaussian Plume Model

About This Project

For the Curious

Imagine a factory chimney releasing smoke. This tool shows you a simplified picture of how that smoke cloud (or "plume") travels and spreads out in the air. You can change things like how tall the chimney is, how fast the wind is blowing, and even how sunny or cloudy it is (which affects how the smoke mixes). This helps us understand where pollution might go and how concentrated it could be at different spots downwind. It's like a weather forecast, but for smoke!

For the Engineer/Scientist

This application provides an interactive visualization of the Gaussian plume model for estimating pollutant dispersion from a point source. Users can adjust key stack parameters (physical height, diameter, exit velocity, gas temperature, emission rate) and environmental conditions (wind velocity, wind direction, Pasquill stability class, ambient temperature, background concentration). The model calculates effective stack height using Briggs plume rise equations and then applies the standard Gaussian dispersion formulas to predict downwind concentrations. The visualization displays the plume, stack, and relevant scales on an HTML canvas, updating in real-time as parameters are modified. This tool can be used for educational purposes, preliminary impact assessments, or "what-if" scenario analysis for single point-source emissions.
